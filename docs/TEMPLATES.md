# Template catalog

Django templates under `templates/`. Every file has a top `{% comment %}` header
(auto-generated by `scripts/document_codebase.py` — refine when you edit a template).

## Layout shells

| Template | Purpose |
|----------|---------|
| `core/base.html` | Master layout: role-based nav, design tokens, CSP, assistant widget |
| `core/marketplace_public_base.html` | Public marketing wrapper |
| `core/seller_layout.html` | Seller sidebar + toolbar |
| `core/onboarding/buyer_wizard_base.html` | Post-signup buyer wizard |

## Navigation includes

| Include | Used on |
|---------|---------|
| `includes/marketplace_public_navbar.html` | Home, catalog marketing |
| `includes/buyer/buyer_navbar.html` | Authenticated buyer (cart, checkout) |
| `includes/tf_header_search.html` | Reusable search form partial |
| `includes/tf_ai_search_assets.html` | AI typeahead CSS/JS |

## Conventions

- English `{% trans %}` msgids; Spanish via `locale/es/`.
- Static assets: `{% static '…' %}?v={{ tf_asset_version }}`.
- Inline scripts require `nonce="{{ csp_nonce }}"`.

See `docs/CODE_DOCUMENTATION_STANDARD.md` for comment rules.
